# Handoff: upstream sync session (2026-11-26) and how to build UCS

For whoever continues this work, in a local Rust session or a new cloud one. Read `AGENTS.md` first.

## The plan in one paragraph

DraftCraft forked from CADCraft (`storytold/cadcraft`, MIT OR Apache-2.0) and has no shared git history with it. We take from it
**conservatively**: only when we reproduce the problem in DraftCraft first (usually by running upstream's own test against our code),
port the fix into our code, and its test passes here. **Our DWG reader and writer are ours alone**: nothing from upstream goes in
them. Our own fixes to our own code (including the DWG module) are fine. The DXF reader and writer are patched by hand where we have
the bug. The ribbon is ours (SkryxDev designs it). The full policy and the divergence table are at the top of
`docs/upstream-sync-plan.md`.

## Tools used in this session (recreate locally)

```sh
# upstream, read-only, as a ref in our repo
git clone https://github.com/storytold/cadcraft ../cadcraft
git fetch ../cadcraft main:refs/remotes/cadcraft/main
```

- **Brand rewrite** for anything taken from upstream: `cadcraft` → `draftcraft`, `CADCraft` → `DraftCraft`, `CADCRAFT` → `DRAFTCRAFT`,
  `CadCraft` → `DraftCraft`; keep `CADCraft contributors`, `craft-fonts`, `craft-libs`, `craft-dwg` as they are.
- **Applying a commit:** `git format-patch -1 --stdout SHA | <rewrite> | git apply --3way` (stage first: `--3way` needs a clean index).
  Apply in upstream's topological order (`git rev-list --reverse --topo-order df659744..cadcraft/main`), not by date: many commits were
  written on old branches and merged later.
- **Fork base** in upstream: `df659744` (2026-11-05). **Snapshot** used for whole-file reference: `414e5442` (last state before
  upstream's unmerged `craft-ui` "next" runtime).
- **Reproduce first:** copy the upstream test file for a fix into our `tests/`, run it; port only if it fails.
- Build tips: the disk filled twice. Use `CARGO_INCREMENTAL=0 CARGO_PROFILE_DEV_DEBUG=0` for test runs and clear `target/debug/incremental`
  if needed. `gpu_viewport_stencil::clipped_viewport_contents_draw_only_inside_their_outline` fails on machines without a GPU
  adapter; it is not ours to fix.

## Building UCS (a new PR, base: #38's branch or `main` once #38 merges)

### What exists

No `UCS` command. UCS records are read from DXF and kept (`Ucs` in `crates/doc/src/tables.rs`); the canvas draws a UCS icon
(`crates/ui-egui/src/viewcube.rs`, `ucs_icon`, `ucs_menu`: only "World" and "Hide UCS Icon"); `View ▸ Viewport Tools ▸ UCS Icon`
toggles it (`ui.toggle.ucsicon`).

### Upstream's UCS (reference)

35 commits, all inside the `414e5442` snapshot. Leave out: `38f51899` (-RENAME), `7d4f35f1` (automation roots, which we don't have),
`d02dc3e9` (DWG via their bridge), `0191a5fa` (-PAN), `a8c50b09` (unrelated regression tests), `23962d68` (parity docs). The first
commit, `bc7357ff`, touches 36 files and does not apply as a patch (it was written against an older upstream tree), so port **top-down**:

1. **Take the new modules from the snapshot** (brand-rewritten): `crates/engine/src/ucs.rs` (frame maths, `UcsFrame`, current and
   named UCS, `Session` helpers) and `crates/engine/src/cmd/ucs.rs` (the `UCS` command with World, Previous, Origin, Z, 3 Point, View,
   Named save/restore/delete, and `UCSICON`). Register them: `pub mod ucs;` in `crates/engine/src/lib.rs`, `mod ucs;` and
   `v.extend(ucs::specs());` in `crates/engine/src/cmd.rs`.
2. **Fill the gaps the compiler names.** Done once in this session; the list was exactly:
   - `crates/doc/src/lib.rs`: `Drawing::ucs_previous: Vec<Ucs>` (init `Vec::new()`; undo restores it with the drawing).
   - `crates/doc/src/tables.rs`: `Layout::ucs: Option<Ucs>` and `Layout::ucs_previous: Vec<Ucs>` (init both).
   - `crates/engine/src/doc_state.rs`: `DocState::ucs_tilted_noted: bool` (a one-time note that tilted frames are 3D).
   - `crates/engine/src/prompt.rs`: `pub fn parse_point_in(text, last, angles, ucs: &UcsFrame) -> Option<Vec2>` (point entry
     in a frame; see the snapshot at line 513).
   - `crates/engine/src/cmd/utility.rs`: `num_text` (number formatting), from the snapshot.
   Check each against the snapshot and take only what UCS needs.
3. **Thread the frame through input**, one area per commit, each with upstream's tests from that area:
   - points, angles and coordinates typed and shown in the UCS: `prompt.rs`, `units.rs`, `pointmod.rs`, `sysvars.rs`
     (`UCSNAME`, `UCSORG`, `UCSXDIR`, `UCSYDIR`, `UCSICON`, `UCSFOLLOW`; commits `bc7357ff`, `a0e023d7`, `56246049`);
   - ortho, snap, grid, polar and object-snap tracking, DIMLINEAR: `9f833f3d`, `3f14431a`, `30e3ae07`, tests `crates/engine/tests/ucs_drafting.rs`;
   - DIST, ID, LIST report in the UCS: `404988f6`, `026f7d90`, `10db46d5`;
   - selection windows in a turned UCS: `5b622c3d`, `9cfe8a6d`;
   - LISP `trans`, `getpoint`, `angtof` (`crates/engine/src/lisp/drawing.rs`, `input.rs`; tests `lisp/ucs_tests.rs`):
     `935e13cc`, `cbacaff9`, `71816944`;
   - UCS View follows the view twist: `ee8922b1`, `c0cc3f85`, `b86caba6`.
   Engine tests: `crates/engine/tests/ucs.rs` (875 lines in the snapshot) should pass at the end.
4. **DXF** (patch our reader and writer by hand): the current UCS per space, named UCS records, `UCSICON` in the active VPORT,
   the axis and origin rules (`821b8ad1`, `d7de5ccd`, `be56597e`, `99b7dc80`, `d75bc7fa`, `a06bb18b`). Test: `crates/io/tests/ucs_roundtrip.rs`.
   **Do not touch `crates/dwg` or `crates/io/src/dwg`**; DWG UCS support, if wanted, is our own work later.
5. **UI**: the UCS icon at the frame's origin and turned with it, its menu (World, Previous, named UCSs, Origin, Hide), the ViewCube menu
   (`viewcube.rs`, `canvas.rs`, `dyninput.rs`). The **ribbon** follows SkryxDev's design from `docs/handoff/ucs-ribbon.md`; until then
   the commands are reachable from the command line and menus. New strings: `it.tsv` (and `zh.tsv`/`zh_tw.tsv` for menu entries).
6. **3D split**: frames tilted out of XY (Z-Axis Vector, X and Y rotation, Object, Face) belong on the `3D` branch. On `main`, keep
   UCS to frames in the drawing's plane.

### Done means

`cargo xtask ci` passes; `tests/ucs.rs`, `tests/ucs_drafting.rs`, `lisp/ucs_tests.rs` and `io/tests/ucs_roundtrip.rs` pass; a CHANGELOG
line under `## Unreleased` ("User coordinate systems: UCS and UCSICON ..."); the PR says which upstream commits were taken (an `Upstream:`
trailer) and which left out.
